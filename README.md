# Памятка пользователю — АвтоСкан

Веб-форма для отправки персонализированных инструкций по входу в системы мониторинга транспорта. Оператор вводит логин и пароль клиента, выбирает систему и менеджера — письмо с инструкцией уходит на почту менеджера автоматически.

**Ссылка:** https://keegooroomie.github.io/autoscan-shiny-octo-invention/

## Поддерживаемые системы

- AXENTA
- GlonassSoft
- Wialon Local
