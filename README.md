# Памятка пользователю — АвтоСкан

Веб-форма для генерации персонализированных памяток пользователя систем мониторинга транспорта. Вводишь логин и пароль, выбираешь систему — скачиваешь готовый `.docx`.

**Live:** https://keegooroomie.github.io/autoscan-shiny-octo-invention/

---

## Как это работает

1. Пользователь вводит логин и пароль
2. Выбирает систему мониторинга (Аксента / ГлонасСофт / Wialon Local)
3. Нажимает «Скачать документ»
4. Браузер загружает оригинальный `.docx`, патчит плейсхолдеры `USER` и `PASSWORD` через [JSZip](https://stuk.github.io/jszip/) прямо в памяти и отдаёт готовый файл

Никакого бэкенда — всё на стороне клиента.

## Структура репозитория

```
├── pamyatka.html          # Основная страница
├── header.jpg             # Шапка АвтоСкан
├── footer.jpg             # Футер АвтоСкан
├── docs/
│   ├── axenta.docx        # Шаблон Аксента
│   ├── glonass.docx       # Шаблон ГлонасСофт
│   └── wialon.docx        # Шаблон Wialon Local
└── .github/
    └── workflows/
        └── deploy.yml     # CI/CD → GitHub Pages
```

---

## Локальный запуск

Открывать через локальный веб-сервер (браузер блокирует `fetch` для `file://`):

```bash
python3 -m http.server 8080
# → http://localhost:8080/pamyatka.html
```

---

## Деплой

Push в `main` → GitHub Actions автоматически публикует на Pages.

Настройка (один раз):  
`Settings → Pages → Source → GitHub Actions`

---

## Обновление шаблонов

Заменить нужный файл в `docs/` и запушить в `main`. Экшен сам всё задеплоит.

Плейсхолдеры в документах: `USER` и `ПАРОЛЬ` → `PASSWORD`. Скрипт также переименовывает «ИМЯ ПОЛЬЗОВАТЕЛЯ» → «ЛОГИН» при генерации.
